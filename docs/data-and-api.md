## 本机保存什么

| 内容 | 保存位置与边界 |
| --- | --- |
| API Key 与服务商配置 | 当前 Android 预览版使用设备 Keystore 的 AES-GCM 密钥加密后写入私有目录。升级时读回校验成功，再清理旧的明文配置。 |
| 应用偏好、模板与资料库 | 偏好保存在本机。模板按会话选用。在历史记录的「记忆」中管理全局条目，每个对话通过「本对话使用全局记忆」单独选用。选择文件夹后可在「文件夹记忆」添加、编辑或删除条目。开启共享后，文件夹中的对话会随消息发送文件夹条目及其中各对话保存的记忆。关闭共享或移动对话后，下一次请求按新的范围发送。删除文件夹需两次确认，会清除该文件夹及当前成员对话保存的记忆，对话回到「全部对话」。 |
| 会话和消息树 | IndexedDB；支持消息分支，未提供应用账号或云端同步。 |
| 已保存的附件原件及元数据 | IndexedDB；本机发送的附件原件会保存，聊天 ZIP 仅导出本地可用的图片原件。 |
| 未发送草稿 | IndexedDB 保存文字和附件原件，同步文字日志补足刷新前的写入间隔；恢复的附件需手动重新上传。 |
| 自动备份与恢复点 | 独立 IndexedDB 保存最近生成的 ZIP、保存状态与最近一次替换前快照；属于本机数据，不能替代外部备份。 |
| 头像与昵称 | 从已登录的 DSH 或 WorkBuddy 账号读取。只登录一个时使用该账号，同时登录两个时可在设置中选择展示哪一个。聊天渠道由会话设置单独决定。 |
| 模型用量 | 本机 IndexedDB 逐次保存请求日期、渠道、型号、操作、状态和服务商回传的 token 计数。记录独立于会话，删除聊天或切换账号后仍可在设置中查看。 |

清除应用数据或卸载会丢失本机记录。退出 DeepSeek 账号会清除本机登录授权，保留 API 配置和会话；删除全部聊天会清理会话、附件和草稿，保留 API 配置及偏好。

## 哪些内容会发送出去

客户端向当前配置的 API 地址发送模型请求。根据所使用的功能，请求可能包含聊天文本、附件、待转写录音、待朗读正文和压缩摘要所需的历史内容。**手动选择附件后就可能开始上传。** 从 Android 系统分享接收的图片先保存在本地草稿，点发送才会上传。切换会话服务商前，可在会话顶栏核对接收地址以及该会话启用的记忆。

Android 的 WorkBuddy 文字通道使用 WorkBuddy 电脑版页面签发的个人账号会话。用户在腾讯页面完成授权，授权凭据保存在由 Android Keystore 加密的应用私有目录中。选用该通道时，DeepChat 将选定的模型、当前对话文本和启用的记忆发送给腾讯。开启联网搜索时，同一模型可以参考最近的对话生成独立查询，例如将「它们的续航呢」还原为此前提到的两个设备。应用通过腾讯检索服务发送短查询，通过腾讯阅读服务读取检索结果中的公开网页。来源总数包含搜索命中，页面阅读步骤单列。模型列表和积分倍率从当前腾讯账号同步，前台会自动刷新，也可手动刷新。明确的零倍率标记「免费」，缺少费率显示「费率未知」，网络异常时保留上次成功记录并标明缓存。在应用的 WorkBuddy 页面可以直接查看和刷新剩余积分，更新时间对应最后一次成功读取余额的时间。开启自动签到后，Android 在联网时调度任务，应用回到前台也会补查。余额读取和签到资格由腾讯按账号分别返回。

对话顶栏和历史列表共用一个标题。发出问题后先从本机文字提取话题。通过 WorkBuddy 或兼容 API 发送较长首问时，首轮完成后可由同一账号和模型再生成一次短标题，按服务商规则计入用量。重新打开旧会话时，应用在本机从历史问题补全缺少的标题。用户手动改名优先。

用户手动选择的位置、当前日期、星期与界面语言可随 DeepSeek 请求中的 `latest_reminder` 发送。应用也会向 GitHub 请求更新清单或安装包。导入下载链接、打开外链与系统分享会产生相应的外部通信。

本地删除会话不等于删除服务商已收到的请求或远端文件。服务端的数据处理规则由相应服务商决定。

## 聊天接口和模型能力

| | DeepSeek 专用接口 | 其他 API 配置 |
| --- | --- | --- |
| 文本对话 | `/anthropic/v1/messages` | 通用兼容网关使用 `/chat/completions`，OpenAI 特定型号使用 `/responses`，官方 Claude 使用 `/v1/messages`。 |
| 流式回复 | 处理正文、思考、结束原因和用量 | 处理正文、公开的思考字段、结束原因与服务商报告的用量。中断时保留已收到的正文。 |
| 深度思考 | 按开关请求思考。收到思考文本时才显示可展开的过程。 | 根据当前服务地址和型号发送对应的思考参数。正文、思考过程与停止按钮使用相同的界面。 |
| 联网与来源 | 官方 Flash 可调用搜索和网页阅读工具 | 按接口和模型启用。引用列表来自实际返回的工具结果或来源标注。 |
| 附件 | 官方 Flash 支持原件上传和引用，Pro 可接收文本 | 按该部署支持的格式处理原件。文字文件可在本机读取后作为消息正文发送。 |
| 语音 | 官方接口支持语音转文字、海星和暗潮朗读 | 官方地址复用相同语音接口。其他服务商可使用设备上已安装并能离线工作的语音功能。 |
| 对话标题 | 首条消息立即生成本机标题，可采用服务端返回的标题 | 首条消息立即生成本机标题，较长的首问可由当前模型生成简短标题 |
| 环境提醒 | 可使用服务端扩展 | 发送普通聊天消息 |

选择供应商后即可搜索内置聊天模型目录。配置了凭据的渠道会自动向当前服务地址读取模型列表，本地实例可以返回已安装或已加载的模型。发现请求只包含读取目录所需的参数与该服务商的凭据。服务商可能按地区、套餐或部署限制可用模型。接口拒绝访问或设备离线时，可继续使用内置目录或填写模型 ID。

Anthropic 官方地址使用 Messages 协议和该渠道的 API Key。OpenAI 官方地址按型号使用 Chat Completions 或 Responses。其他兼容部署按所填地址与模型 ID 发送请求。不同渠道的同名模型可能提供不同的思考、附件或搜索能力。

### 使用 Anthropic 官方 API

在「设置 → API 配置」中选 **Anthropic Claude**，填写工作区 API Key，选择模型并保存。应用会从 `GET /v1/models` 分页读取此 Key 可用的模型。普通聊天、续写、自动标题和上下文压缩都使用所选模型的完整 ID。浏览器和 Android WebView 直连 `api.anthropic.com`，请求带 `x-api-key`、`anthropic-version: 2026-10-21` 和浏览器访问许可头。仅在自己信任的设备上输入 Key。[模型目录](https://platform.claude.com/docs/en/api/models/list) · [API 版本](https://platform.claude.com/docs/en/api/versioning)

支持思考开关的型号按能力使用手动预算或自适应思考。Sonnet 5.5 关闭开关后仍可在工具调用之间思考。始终思考的型号只提供摘要显示开关。可展开的内容来自 Claude 返回的公开摘要。已授权的原生联网搜索可以显示查询、结果与引用，调用次数和费用由服务商决定。遇到 `pause_turn`，应用显示暂停提示，用户可以另发一轮。原件支持 PDF、PNG、JPEG、GIF 和 WebP，上传后的文件 ID 受工作区约束。[思考模式](https://platform.claude.com/docs/en/build-with-claude/thinking) · [联网搜索](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool) · [Files API](https://platform.claude.com/docs/en/build-with-claude/files)

开发验证通过模拟响应覆盖设置、对话、标题、摘要与用量。生产连通性、模型授权、工作区搜索开关、文件额度及实际账单需使用对应的真实 Key 验证。Claude 报告的输入用量由普通输入、缓存写入和缓存读取三项相加得到，缓存读取同时计入输入命中。[流式响应](https://platform.claude.com/docs/en/build-with-claude/streaming)

## 在应用内查看模型用量

打开 **设置 → 模型用量** 即可查看输入与输出 token 趋势、渠道和型号用量排行，以及输入、输出缓存命中图。在排行中点选渠道或型号，图表和请求明细会同步筛选。今天按小时展示，近 7 天和近 30 天按日展示，较长的全部历史按月分组。对话、重新生成、续写、自动标题、上下文压缩和 WorkBuddy 搜索规划分别计数。查看本机记录无需登录。聊天 ZIP 只处理对话数据，导入历史后本机请求账本仍保留。

输入、输出分别展示服务商返回的 token 总量、缓存命中量和命中率。显式返回的 `0` 显示为零，缺字段显示「未提供」，部分请求有值时注明覆盖次数。每个方向的命中率只采用同时返回该方向命中数和总量的请求，加总后计算。DeepSeek 的前缀复用属于输入缓存，之前生成的回答在后续请求中命中时，计入后续请求的输入命中。平台账单及其他客户端发起的请求以服务商的账号记录为准。[DeepSeek 缓存说明](https://api-docs.deepseek.com/guides/kv_cache) · [Magpie 请求用量参考](https://github.com/yetone/magpie/commit/8b70b7d976f6308c7e8ceb24460d1faba961877e)

## 聊天导入与导出

客户端使用 `export_format_version: 3` 的历史格式，并通过可选 `deepchat_context` 扩展保存上下文选择与摘要来源。导入兼容 ZIP 时先确认、校验和暂存；校验完成后成功创建本机恢复点，才在事务中替换全部会话与附件。**导入不是合并。**

导出保留消息树、当前分支、上下文排除轮次、摘要检查点及本地存在的图片原件。单条删除后保留的回答带有原始问题归属，避免导入后错误配对。非图片附件仅保存元数据，不包含文件原件；API Key、应用偏好和未发送草稿不属于聊天导出，因此不能把 ZIP 当作完整应用快照。

自动备份默认每 10 个新完成用户轮次在后台生成一次本机 ZIP，并短暂提示关闭入口。同一轮重新生成或续写只计一次。打开设置的数据管理页，可关闭以后自动生成，也可仅删除已有的本机自动备份。聊天、导入恢复点和 WebDAV 备份分别管理。用户手动下载或分享后，可确认保存的位置。创建恢复点时另行保存全部本地附件原件和草稿，导入、清空、恢复前写入失败均中止替换。历史与草稿位于不同数据库，恢复草稿失败会明确报错且保留恢复前快照。清除应用数据或卸载会同时清除本机备份。

导入支持单卷 ZIP32 和 ZIP64 的 STORE / DEFLATE。导出写入单卷 ZIP32。加密 ZIP 或多卷归档需先另存为未加密的单卷文件。Android 下载历史链接使用原生文件下载；Web 使用 `fetch`，受链接有效期和跨域响应影响。格式细节见 [历史文件格式](../chat-demo/src/services/chat/history/README.md)。

## 上下文估算与压缩

上下文圆环按当前模型的预算估算历史占用。选中模型时优先读取当前账号或实例返回的窗口，其次查询同一供应商和模型 ID 的公开规格。在「设置 → 模型上下文」中可查看来源，单独修改并恢复默认。服务商只给出最大输入时，界面会注明这是输入上限。规格尚未公布的模型会标明临时预算。实际计费以服务商为准。[各渠道默认值与型号清单](model-context-windows.md) · [目录来源](../tools/model-catalog/README.md)

例如，DeepSeek 官方 `deepseek-flash` 的总窗口为 1,048,576 tokens，最大输出为 393,216 tokens。WorkBuddy 的 `deepseek-v4.1-flash` 优先使用当前腾讯账号明确提供的最高可选档位，离线内置参考预算为 1,000,000 tokens。手动选档或输入预算后保留该值，点「恢复默认」会重新使用当前最高可用档。修改预算会调整本机占用估算和摘要触发时机，服务商仍按账号授权接收请求。[DeepSeek 模型说明](https://api-docs.deepseek.com/zh-cn/api/list-models/) · [WorkBuddy 模型说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model)

可以逐轮包含或排除历史，也可快速选择最近 5 / 10 轮。实际请求和用量估算采用相同的当前分支、轮次选择与摘要来源校验。切换分支、排除摘要涵盖的轮次或删除摘要来源时，不会继续发送失效摘要。

达到 80% 后，用户可以确认手动摘要；默认关闭的自动摘要可在上下文面板启用，发送前预算达到阈值时调用当前模型。旧轮次超过单次摘要预算时按完整内容分批处理，不通过裁掉开头来凑窗口。近期保留预算目标约为窗口的 16%，并非固定保留 16% 的消息数。当前问题与续写前缀始终保留；取消、断流、空结果、拒绝、截断、配置变化或摘要未缩短时保留原文和旧摘要。

原始消息仍保存在本机。摘要可以查看与编辑，也可以恢复完整上下文。摘要可能遗漏细节或产生误记；长历史可能产生多次模型请求。重要记录应先导出备份。

## 删除范围

消息菜单支持仅删除当前消息或删除当前消息及全部后代，后者包含隐藏分支。三次确认依次核对范围、消息与最终删除；任何一步取消都不改变数据。最终执行时再次验证消息 ID 集合，范围已变或正在生成时拒绝删除。

单条删除会重接后续分支并保留所有其他消息。回答通过 `contextUserId` 记录原问题归属，孤立回答只展示，不参与请求轮次，也不能重新生成或继续。共享附件仍被其他消息引用时保留原件；摘要涵盖被删消息时清除摘要，防止继续发送已删除内容。
